 6. Python AI runtime dependencies
 .
 THIRD_PARTY_LICENSES.txt records the locked runtime distributions, their
 wheel license declarations, the license and NOTICE files found in the
 installed wheels, and, for each text a wheel omits, the pinned upstream URL
 and SHA-256 the generator verifies.
 .
 The application dynamically loads Psycopg, including the psycopg-binary
 extension. The Psycopg wheels declare LGPL-3.0-only. The Python AI image also
 conveys these LGPL native libraries as separate shared objects, resolved at
 run time through $ORIGIN rpaths, so a recipient can replace each one with an
 interface-compatible build:
 .
