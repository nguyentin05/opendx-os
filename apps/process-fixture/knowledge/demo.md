# Independent review fixture

Backend C0 demo only. Employees and optional CLEAN quote attachments use same-workspace foreign keys. OPEN → IN_REVIEW → DONE/DECLINED is independent of procurement. submit creates one review work item through the declared create_review effect. Manager self-approval is denied. This fixture implements no OT, AI, BI, maintenance or timesheet policies. Registry publication, SQL/Hasura permissions and workflow import remain B prerequisites.
