# Tài liệu tham chiếu API

| Trang | Nội dung |
| --- | --- |
| [Các route của capability](capability-routes.vi.md) | Các route HTTP của `dxos-authz`, cap-hr, cap-process, cap-data và cap-ai, cùng trạng thái triển khai và khả năng sử dụng của từng route |
| [Triển khai workflow và sự kiện](events.vi.md) | Việc tiếp nhận Kestra flow, định tuyến sự kiện và các callback phản hồi tác động |

Trang về các route cho biết những route nào đang được đưa vào sử dụng; các route của cap-data hiện vẫn chưa được triển khai.

Các đặc tả ranh giới có thể đọc bằng máy vẫn được lưu tại `contracts/runtime-v1.openapi.yaml` và `contracts/events-v1.schema.json`.
